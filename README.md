# Pac-Man (Python / Pygame)

This is a simple Pac-Man game built using Python and Pygame.  
The game includes player movement, ghosts AI, collectibles, scoring system, and win/lose screens.

---

## Features

- Player movement on a grid-based map
- Ghost enemies with simple AI
- Berries and big berries collection
- Score system
- Lives system
- Power mode (ability to eat ghosts)
- Win screen when all berries are collected
- Game over screen when lives reach zero
- Main menu system

---

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/pacman.git
cd pacman
pip install pygame
```
